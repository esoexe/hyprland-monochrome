hyprland-monochrome

A clean monochrome Hyprland desktop for Arch, EndeavourOS, CachyOS and Manjaro. This page is generated from the project's own configuration files, so nothing here is aspirational — it is what the files actually say.

Hyprland 0.55+ · Lua config 168 keybinds 64 packages, all official repos 4 optional AUR extras kitty · thunar · Zsh + Starship MIT

01Desktop layout & Wallpaper Studio

Tiled windows with 5px inner and 10px outer gaps, 10px rounding, a focused-window border that goes white-to-grey, monochrome GTK3/GTK4 overrides, and a frosted top bar with live Pomodoro/Zen and modal submap pills. Rofi slides in over the top for the Command Palette, launcher and visual pickers.

Vector layout drawn to the real gap, rounding and bar geometry from modules/appearance.lua (docs/preview.svg).

07Try it

Install

./install.sh
Packages, backups (twice), configs, wallpapers. --dry-run shows the plan first.

See the keys

Super + /
Searchable cheat sheet built from your live binds, or read docs/KEYBINDS.md.

Make it yours

modules/user.lua
Programs, gaps, keyboard, paths — the other modules read from it. Right now: browser firefox, terminal kitty.

Pick a wallpaper

Super + W
Thumbnail grid over ~/Pictures/Wallpapers, or --random on every boot.

Record it

Super + Alt + Print
screen recording (again to stop) · Super + Alt + S saves the last minute · gpu-screen-recorder or wf-recorder, whichever you have.

System settings

Super + I
Info, Network, Bluetooth, Monitors, Sound, night shift, and every config file.

Command Palette

Super + Shift + P or Super + ;
Jump to open windows, trigger focus/layout actions, or type = 1920*1080 for live math.

Deep Work & Zen

Super + Z · Super + Shift + Z
One-key distraction-free Zen framing + Waybar Pomodoro countdowns & DND.

Modal Chords

Super + R · Super + C
RESIZE mode (h/j/k/l + 1-3/0 gap presets) and single-chord CAPTURE + OCR.

Undo everything

./uninstall.sh
Removes the config and restores your originals from ~/.config-backups/pristine.

# the short version
git clone <this repo> && cd hyprland-monochrome
./install.sh            # then log out and back in
./test/run-all.sh        # shellcheck + lua + json + 120+ smoke checks
