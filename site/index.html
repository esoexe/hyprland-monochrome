mono-open Dispatcher

        

        
Unified launcher for desktop entries, Flatpak IDs, executable AppImages (automatically falling back to --appimage-extract-and-run when FUSE is absent), URLs, and local files.

      

      

        

          
            
          
          
Toolkit & Java Fixes

        

        
Configures ELECTRON_OZONE_PLATFORM_HINT=auto, _JAVA_AWT_WM_NONEREPARENTING=1, QT_QPA_PLATFORM="wayland;xcb", and unblurred XWayland scaling out of the box.

      

      

        

          
            
          
          
XDG Portals & Polkit

        

        
Auto-starts xdg-desktop-portal-hyprland, GTK file chooser fallback, GNOME Keyring, and a graphical Polkit agent so privileged prompts and screen sharing work reliably.

      

      

        

          
            
          
          
Fallback Application Chain

        

        
mono-default-app resolves your preferred browser, terminal, editor, or file manager dynamically with graceful multi-candidate fallback across freshly installed machines.
